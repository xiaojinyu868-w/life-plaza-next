# 插电工坊完整课堂演示与录制

2026-11-09 修订。供展示操作者与录制人员使用。按最新反馈，主片展示学习者如何完成这一课，并补充真实发生的制作过程。原 DOCX 中的插电前后对照路线不再作为主片脚本。

本版课堂选取第 4 课的零件词汇、“也”和“……，对吗？”作为教学目标，依次经过入门、X 光透视台、并联接头、教小龙、质检和出厂。它不是设计提案中全部九站及教材每一页的完整实现。

## 当前录制条件

已具备可离线完成的课堂、课程内容文件、语料来源卡和教师提示。教师入口改为完整课堂，默认显示本课语料快照；对照面板需另行打开。语料开关与“联机”开关始终独立。

幼年版和青少年版小龙已由国内 Tripo 生成，并实际载入课堂。入口可以选择形象，课中可用顶部“小龙”按钮切换，学习进度保留。两版当前是静态姿态模型，沿用课堂中的整体移动和轻微待机起伏，没有骨骼走路、口型或独立肢体动画。青少年首个结果缺少双角，已排除；最终采用关闭自动修图后保留双角的版本。三次生成合计消耗 180 积分。

原始 4K 模型单独保留；课堂使用 2048 像素贴图版本，几何、UV 和材质引用保持一致。`t10.html` 提取出的 98,304 点场景已目检为古风室内，不是汽车车间；当前继续使用代码车间。

正式成片前，以最终构建重新检查本页路线。现场未配置或未验证的云对话、语音评测与多语言能力，不放入“已经可用”的讲解。

## 开场前检查

1. 在项目目录执行 `npm run build`。双击 `dist/插电工坊.html` 可离线演示；需要服务器能力时另执行 `npm start`，打开终端给出的本机地址。
2. 使用 Edge 或 Chrome，先在实际投影分辨率走一遍。主录制建议 1920×1080；还需检查 1366×768 的纠错卡、字幕及输入区。
3. 进入“教师演示 · 完整课堂”，听王明首句。浏览器没有可用中文声音时使用字幕，并说明本机未播放语音；不要把静音截图写成配音验收。
4. 语音输入先查看音频去向并确认授权。没有可用语音时可打字、输入拼音或点选。演示采用哪一种输入，就如实说明。
5. 关掉通知。按 F5 可回到入口；顶部站名可供排练定位，但正式完整流程验证需要从入门走到出厂。

## 完整课堂主线

### 入门和认识零件

进入第 4 课，让王明用“你是马丁，对吗？”建立角色。展示目标零件、示范读音与词卡，再完成辨认和表达。镜头要同时看见语言目标与对应物体，不把字幕和车辆切成互不关联的两段。

建议旁白：“这一课把词汇和句式放进车间任务。先看示范，再辨认，最后自己表达。”

### 练习也的位置

进入并联接头，先选择句子，再故意放错一次“也”，展示具体提示和修正后的动作。继续完成正确回答。不要用“未接语料只能说错了”来制造对照；两种模式都应给出正确教学。

建议旁白：“错误会得到具体反馈；学员可以用提示，再尝试一次。”

### 教会小龙

让学习者纠正小龙、说明两种动力的关系，再完成关联词汇的迁移。可通过顶部“小龙”按钮短暂展示两种形象，随后选定一种继续课堂。录制实际课堂中的模型，不以参考图或下载预览替代。

建议旁白：“这里换学员来解释。小龙的提问帮助他把刚学的表达再用一次。”不要据此声称一次答对就证明长期掌握。

### 质检和出厂

区分三种车，练习判断、补充正确说法，最后用“……，对吗？”提出问题。完成出厂后展示表达尝试、语音作答与提示记录。打字、点选和自报跟读不等于检测到开口；识别文字通过也不等于发音测评通过。

建议旁白：“完成一课后，老师能看到参与记录，还需要结合实际表现判断学生掌握了什么。”

## 制作过程怎么录

制作过程应来自真实操作。当前可录以下链条，并在剪辑中保留“内容编写与审核”这一步：

1. 展示本课目标词及教材对应范围，例如“发动机、驱动电机、动力电池、也、对吗”。只展示有权用于展示的教材片段。
2. 打开真实课程内容文件 `content/lessons/nev-l4.json`，定位一条台词和相应的教学步骤。说明教学目标、提示和场景动作如何关联。
3. 在课件里打开一条“语”来源卡，展示原句、检索式、频道与提供包记录的获取时间。当前使用离线快照，没有重新检索的镜头就不要说“现在实时搜索到了”。
4. 展示审核后的课程内容及 `assets/models/` 中的模型、`generation.json` 任务记录。可以呈现幼年参考图到实际 3D 模型的结果，以及青年版保留双角的修正过程。不得拍到 Key、账号或下载签名。
5. 执行构建，重新打开生成的 HTML，展示刚才准备的内容如何出现在课堂里。保留原始录屏，方便核对制作过程与最终文件。

当前没有“上传任意课文截图，自动检索并生成完整 3D 课程”的一体化入口。可以把它放在后续方向中；不能把预制课程回放剪成已经自动生成。

## 成片结构

短片可用约三分钟呈现一条连贯学习路线：目标与入场 → 零件表达 → 句式纠错 → 教小龙 → 出厂；制作过程另接一小段。较长展示可保留更多学习者尝试和来源卡。时长是剪辑建议，不是实测课时。

先录一遍完整、不跳站的过程，验证没有断点，再剪辑重点。保留一次可恢复的错误和一次独立表达。画面上的声源、字幕和操作应对应同一次真实运行；合成语音、替代输入和演示样例要注明。

## 讲解用语

- 来源：“提供包附有检索快照；标注的条目可以查看来源。本轮没有重新回源核验。”
- 教学改写：“这句话依据偏误样例改写成车间情境，原句可在来源卡查看。”
- 分级：“通用词汇按官方大纲查级，场景必需的专业词单列。查词表不等于句法和语义都已审完。”
- 对话：“课堂判题由本地规则控制；联机回答需要配置服务并经过校验，失败时可继续课堂。”
- 发音：“语音识别、指定文本跟读和声调测评分别处理；没有真实结果时不显示分数。”
- 场景与人物：“只展示当前实际载入的资产，不把模型预览、古风样例或计划中的车间算作已完成。”

原手册中的 397、15/20、109 等数字只代表提供包记录的特定查询或抽样；本主片无需这些数字。不要推成国别错误率、车间口语普遍性或学习效果提升。

## 最终录制验收

- 最终 HTML 能独立打开，课堂从入门走到出厂，错误后能继续。
- 两种小龙是真实生成并载入的 3D 模型；尺度、朝向、纹理、遮挡和动作已经目检。
- 1920×1080 与 1366×768 的字幕、输入区、纠错卡、车辆和标签没有关键遮挡；手机检查另行记录。
- 所讲的模型、语音、语料能力与本次实际配置相符。
- 制作过程中的每个成功步骤都有真实文件或任务结果可核对，录屏不含凭据。
- 未完成项留在验收记录，不通过旁白或剪辑掩盖。
