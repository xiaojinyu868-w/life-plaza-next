整理于 2026-11-07。材料：用户提供的“标准录音 404”“标准录音 405”、截图、API 文档，以及本机代码。转写存在错字、说话人编号漂移和未完成句子；不据此认定具体身份、事实背书或已经承诺的交付日期。原始录音转写及私人经历不进入仓库。

## 1. 两份讨论如何合起来

404 讨论近期产品：把教材与教学经验变成有过程、有脚手架、有输出的中文学习体验；教学场景可以包含职业中文，但目的仍是语言学习。405 讨论长期动机：让学习基础弱、缺少支持、不敢开口的人获得被看见的机会，把好的教育经验沉淀进可复用、能持续发展的产品。

这不是单纯把教材搬进 3D。3D 的价值需要由语言与行动的关系证明：听懂或说出一句话后，物体、人物或任务发生有意义的变化。

## 3. 小龙承担什么

小龙是学习伙伴：学习者可以教它一个词、一句话或一个做法，小龙通过提问与尝试让学习者继续表达。成长应来自具体能力证据，而非随意增加的经验值。

需要分清两个环节：

- 任务内反馈：这一次是否理解指令、选对对象、表达清楚；出错时给合适的提示或示范。
- 任务后迁移：换一个对象或生活情境，是否还能使用同一个词或结构；小龙在这里请求帮助。

404 中“小龙何时出现、任务失败怎样处理、复习是否重复”有真实争论，没有完全定案。实现时不能直接把某一句设想当成最终交互规则。

建议：小龙保持友善与好奇，但不能确认错误知识。把“我没听清”与“表达有误”分开；识别不确定时提供重试和替代输入，不让学习者在同一句上无限卡住。普通 ASR 转写正确不等于发音测评通过。

## 4. 当前首课与可验证闭环

2026-11-08 更新：后续交付的《技术任务书》与插电工坊深化包已把首课明确为新能源汽车车间第 4 课。早期“先用梵高房间”只是建议，现已被车间方向替代。当前流程为入门 → X 光透视台 → “也”并联接头 → 教小龙 → “对吗”质检台 → 出厂，以课程 JSON 为准。

下面“打开窗户”仅保留为讨论教学闭环的例子，不是另开的开发任务：

1. **示范**：人物说“窗户”，指向窗户，并展示与目标等级相适应的用法。
2. **有提示练习**：识别对象，再在有限选项中选择动作；可看拼音、听示范。
3. **独立表达**：学习者用中文表达开窗意图，系统判断语义与当前教学目标是否匹配。
4. **行动反馈**：窗户打开，人物自然重述正确表达；语言、动作和反馈一致。
5. **教会小龙**：小龙请求帮助完成相关但不同的行动，学习者解释或指挥。
6. **迁移**：换到“打开门”等语境，撤掉部分提示，观察是否能独立使用。
7. **学习记录**：区分听懂、选对、跟读、独立说出与迁移成功，不把看过词卡记作掌握。

真实语料用于候选例句与可追溯的用法证据；知识图谱用于核实可用的词、关系与等级。示例句只有在实际查到后才能标注为检索所得。场景改写必须另标为改写。

## 5. 分级与自适应建议

- 将目标分成“基础等级允许的表达”“本课必需词”“可选拓展”，并记录每个目标的理由。
- 给专业词提供可见对象、母语释义、拼音和示范；专业词的出现不自动要求学习者会写。
- 难度同时考虑句法、句长、陌生词数量、提示强度与任务步骤，不能只查词表。
- 根据实际作答与提示使用调整下一步；母语/国别只能在确有数据和适用条件时辅助设计，不能代替个人表现。
- 共字关系不等于语义关系，也不等于学习先修依赖。比如“斧头”的“头”不宜机械解释成“脑袋”；需查实际词义和语用，不能用假词源制造迁移。

## 6. 真实数据接入的验收

用相同场景、目标等级和任务，对比现有模型方案与检索增强方案。提前固定样本与评分规则，保存失败样例，不能只挑出好看的片段。

| 维度 | 观察内容 |
| --- | --- |
| 教学正确性 | 例句、搭配、词义、纠错是否准确；由具备中文教学经验的人审阅 |
| 难度 | 超纲的非目标词、句法复杂度、需要多少提示 |
| 行为闭环 | 语言意图能否触发正确行为，识别失误能否恢复 |
| 掌握与迁移 | 从提示练习到独立表达，再到新语境使用 |
| 来源 | 能否区分原文、改写、生成；检索记录能否回溯 |
| 可用性 | 延迟、失败率、配额消耗、降级后是否仍可完成基础任务 |

展示视频可以呈现前后对比，但“接入语料必然无错误”不是验收结论。旧文档的超纲比例数据只能标为历史报告，需重新复测。
