# 运行与部署

公网静态演示使用 [GitHub Pages](https://xiaojinyu868-w.github.io/life-plaza-next/)，学院服务器与云端服务仍需独立部署。旧仓库的 nginx 配置、域名、端口与发布命令不用于本项目。

## 公网演示与自动更新

`.github/workflows/deploy-pages.yml` 在 main 的应用、课程、模型或发布脚本变化时运行，也可从 GitHub Actions 手动触发。构建使用 Node.js 24，无需安装应用依赖；`node scripts/build-pages.cjs` 调用原有构建，将完全相同的单文件课堂复制为 `dist/pages/index.html`。

Pages 只发布 `index.html`、`.nojekyll` 和 `version.json`，不上传仓库根目录、本机配置、教师数据、录音或原始交付文件。`version.json` 记录源提交、HTML 的 SHA-256 与大小，供核对当前实际发布版本；Git 推送成功不等于 Pages 部署完成，须等待工作流部署成功及公网访问验证。

该链接支持完整六站课堂、两种小龙、内置词表与语料快照。它没有 Node 后端，因此云对话、云语音/评测、实时语料回源和教师汇总不在本次部署范围。初始保持离线教学模式；浏览器自身语音能力也不等于已部署语音供应商。

回退课堂时，恢复所需源码/模型版本后推送 main 并等待工作流完成，或在 GitHub Actions 对相应提交重新执行发布；始终核对线上版本元数据与页面内容。

## 本机与离线

Node.js 22+ 下运行 `npm run build`、`npm start`，访问 `http://127.0.0.1:5198/`。默认不调用云服务。`dist/插电工坊.html` 可直接离线打开，包含两课内容；`dist/teacher.html` 需要服务端才能读取汇总。

复制 `.env.example` 为本机 `.env` 后，按选定服务填写配置。`npm start` 读取该文件；修改配置需要重启进程，仅保存文件不会改变运行中的服务。已存在的其他项目密钥不会被自动读取或拷贝。

## 学院或服务器

1. 确认部署域名、音频与模型的处理地域、教师访问凭据及数据目录。
2. 在独立目录构建。配置 `HOST`、`PORT`、`WORKSHOP_PUBLIC_ORIGIN` 与 `WORKSHOP_TEACHER_TOKEN`；非本机监听缺少后两项时进程拒绝启动。
3. 由目标服务器的反向代理提供 HTTPS，转发原始 Host，并限制请求体与连接时长。手机麦克风要求安全上下文，普通局域网 HTTP 不能作为语音验收环境。
4. 给 `WORKSHOP_DATA_DIR` 配置独立可写卷，只让应用账号访问。里面包含匿名事件与语料缓存，不能当静态资源发布。
5. 首先不配置任何第三方服务，验证离线课程、状态接口与教师访问控制；再逐个配置服务。模型和语音未配置时应该降级，而非让课程无法继续。
6. 启用云语音前，为每个实际使用的服务填写 `.env.example` 中的提供方、地域、音频保存规则及隐私说明链接，并填写运营方。若同时启用识别与评测，两套说明都要填写；腾讯评测使用 `WORKSHOP_ASSESSMENT_*`。应用根据运行配置在首次录音前展示，重新联机会再次确认；设置了 `WORKSHOP_PUBLIC_ORIGIN` 但缺少所需说明时拒绝启动。字段由部署方核实，不从域名猜地域或替厂商承诺不保存。
7. 真实模型、语音和语料回源按 `ACCEPTANCE.md` 单独验收。默认并发上限为 8，班级 30 人场景须结合供应商配额与实际压测调整，不把本机自动测试当成容量证明。

可选容器入口是根目录 Dockerfile。镜像用非 root 用户运行，只复制明确的源码路径，不复制 `.env`、教材原页、录音或交付 ZIP。运行时通过容器平台注入环境变量，挂载 `/app/data`。当前环境尚未构建或启动此容器，镜像部署待在目标环境验证。

## 密钥、数据与退回方式

- `.env.example` 只有空值/默认值。平台 Key 只在服务端，教师凭据只用于汇总接口访问，不进入前端构建产物或浏览器持久存储。
- 语料服务复用现有 Token，不登录重新签发，以免影响团队正在使用的 Key。快照与 30 天缓存可减少回源请求，但未知上游格式仍明确未验证。
- 应用不写录音或自由文本转写；事件只保留允许的课程字段。供应商侧的音频留存不受应用“不落盘”承诺覆盖，必须单独确认。
- 匿名事件默认保存30天、单文件最多64MiB。这是可配置的工程默认值，尚未由学院确认；`WORKSHOP_EVENT_RETENTION_DAYS=0` 仅关闭新增保存，不删除旧记录。过期清理在写入或教师读取时发生，并非定时器。容量满返回507，不自动丢弃近期课堂；异常旧记录保留但不计入汇总，教师可见异常数量。停机备份、备份保留期与机构最终保存政策由部署方管理。详见 [事件保存](EVENT-STORAGE.md)。
- 请求限流分为每IP每分钟6000次、每随机会话每分钟180次，可分别配置。同一学院出口或代理不会让30个学生共用180次额度；不信任客户端 `X-Forwarded-For` 绕过限流。模型/语音日会话额度和供应商并发限制仍独立生效。这些限制存在于单个进程内，重启会重置；随机会话不是身份认证或账户总账单限额，正式公开服务需目标平台的访问与费用控制。
- 当前事件队列和限流适用于单进程。不要让多个进程或容器同时写同一个事件文件；扩展实例数前先替换为共享数据库和统一额度控制。
- 更新时保存上一份构建和服务版本。需要回退时恢复该版本并重启，保持数据目录；不要运行旧项目的部署脚本或覆盖它的未提交文件。
- Git 推送前执行 `git remote -v`，目标必须是 `xiaojinyu868-w/life-plaza-next`。
