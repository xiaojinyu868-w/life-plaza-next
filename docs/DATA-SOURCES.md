## 两套认证

语料库：`POST https://corpus.chineseplus.net/api/v1/token`，请求字段 `email`、`password`；读取 `access_token`、有效期及配额。重新签发会使旧 Key 失效，不能每个请求都登录。实际额度以账号响应为准。

知识图谱：`POST https://kg.chineseplus.net/out/api/auth/login`，请求字段 `username`、`password`；返回 JWT。附件说明账号需审核，结果受可见标签权限过滤。截图提供的是语料库账号，不能假设两服务共用账号。

两者请求均用 `Authorization: Bearer …`，但凭证不可混用。浏览器不持有平台账号、密码或平台 Token。

## 语料查询

`POST https://corpus.chineseplus.net/api/v1/search/{channel}/corpus`

请求体为 `{ "query": "检索式" }`。频道：0 教材、1 教学视频、2 中介语、3 母语口语、4 母语书面语。Context 返回语境实例，Freq 返回频次统计；具体语法应遵循所选频道标注体系与官方帮助。

先用少量受控查询验证响应，不预先编造 response schema。记录频道、检索式、获取时间、可用来源标识以及原文/改写的区别。

## 图谱查询

- `POST /out/api/intelligent/nl-to-cypher`：自然语言生成查询。附件规定 query 1–500 字符。
- `POST /out/api/intelligent/execute-cypher`：执行查询，传 `cypher`、`parameters`、`limit`；附件的默认 limit 不限量，因此客户端必须显式限制。
- `GET /out/api/health`：健康检查。本次网页工具访问未成功，不能据此判断服务停机。

生成查询用于探索；稳定的产品路径优先用经过核对的只读参数化模板。附件中的 `Character`、`Word`、`hskLevel`、`NEAR_SYNONYMOUS_WITH` 只是已提供的示例，不假定存在额外关系。不要把权限过滤后的空结果直接解释成“这个知识不存在”。

## 接入位置与建议契约

现有入口是学中文的 `server/learn/api.mjs::graphOf()` 与 `server/learn/hsk.mjs::chainOf()`。后续完整教学任务还需要共用检索服务，不能只更换词卡函数就声称完成了自适应教学。

建议内部结果使用明确来源字段：`provider`、`status`、`retrievedAt`、`sourceRef`（上游提供时）、`query`、`originalText`、`transformedText`、`evidenceType`。这是拟定的内部契约，不是上游已存在的字段。

状态至少区分：真实命中、无结果、权限不足、额度/频率限制、服务错误、生成补充、未接入。用状态驱动展示与降级，不把生成补充放进“真实语料”栏。

## 使用边界

官方文档将资源使用限定于获批活动用途，并要求成果说明调用方式、使用场景及效果。未来商业扩展的授权需另行核实。本次仅阅读文档，没有登录、签发 Token、调用付费模型或下载语料集。

下一步先确认已有 Token 管理方式、图谱独立账号与可用标签，然后验证最小返回样本。考试题库、母语偏误比例和先修关系在验证前保持“待确认”。
