# 插电工坊技术路线与 M0 调研

核查日期：2026-11-08。依据本次交付的《技术深化任务书 v1》《01_接口与数据规范》《02_教学设计说明》和原型源码；供应商事实来自下列官方文档。本文是方案与采购前核查，不代表真实服务已开通、效果已通过或用户已选择部署地域。

## 1. 本轮对象与路线

本轮交付对象是《职通中文：新能源汽车技术（初级）》第 4 课“认识插电式混合动力汽车”的**插电工坊深化**。它取代此前文档中梵高场景等首课建议；人生广场提供长期产品方向，借光不在范围内。任务书 A–D 四个模块均在范围内，E 是可选教学机制，不将种子想法自动变成承诺。

保留现有自写 WebGL、原生 JavaScript 和单文件构建；先把课程内容、网络适配、判题与渲染隔开。状态机决定站点、教学目标和对错；模型提供受约束的问答与措辞。`logic.js` 继续保持纯函数，不能承载网络或 DOM。每项联网能力必须能关闭，语料“插电”与网络“联机”是独立开关。

| 路线 | 本轮代价与收益 | 判断 |
| --- | --- | --- |
| 保留当前 WebGL | 保住已交付的相机、部件动画、热区和双路径；补降采样、数据驱动课程与适配器。仍需承担自写渲染器兼容、内存和排序维护 | 本轮执行路线；风险能逐项验证，避免同时重写教学与图形 |

### 2.1 接口挂载与结果边界

对外统一 `POST /api/speech/evaluate`，密钥、签名、厂商地址和重试都在服务器。浏览器只访问自己的服务。请求携带 `mode`、`refText`、匿名 session、课程/站点/步；原始录音在内存内处理，设置大小和时长上限，取消时释放资源。

- 腾讯服务端 WebSocket：`wss://soe.cloud.tencent.com/soe/api/<appid>`；请求签名按[官方协议](https://cloud.tencent.com/document/product/1774/107497)。中文句子设 `server_engine_type=16k_zh`、`eval_mode=1`，`ref_text` 加 `{::cmd{F_TDET=true}}` 前缀。只有 `Words[].Tone.Valid=true` 且调值有效才映射 `tone.ref/got/ok`；无效、null、-1 均标“未评测”，不能默认正确。中文句子上限 30 字/60 秒，长句需教学拆分。[声调参数](https://cloud.tencent.com/document/product/1774/107396)
- 讯飞服务端 WebSocket：`wss://ise-api.xfyun.cn/v2/open-ise`，AppID/APIKey/APISecret 签名。按实际中文题型解析 XML；拒识结果不能作为可信分数。`perr_msg` 是错误类别，不是“实际读成第几声”；没有明确识别调值就让 `got=null`，不能从参考拼音倒填。[API 与字段](https://www.xfyun.cn/doc/Ise/IseAPI.html)
- 两者要求 16 kHz、16 bit、单声道等指定编码；浏览器的 `webm/opus` 不能改个 MIME 就当 WAV。采用浏览器 PCM→WAV，或服务端真实转码并检查头部/采样率。保留音频原始测量，不拿模型模拟返回冒充云分数。[腾讯传输格式](https://cloud.tencent.com/document/product/1774/107497)、[讯飞格式](https://www.xfyun.cn/doc/Ise/IseAPI.html)
- 已录完的 WAV 可在腾讯设 `rec_mode=1` 单片提交（最长60秒、每连接一次）；默认实时模式则按约40ms音频/40ms间隔发送。不要把整段文件高速发送给实时模式。[录音与实时传输](https://cloud.tencent.com/document/product/1774/107497)
- Azure 用所选区域的 Speech SDK 配置 `PronunciationAssessmentConfig`；`referenceText` 有/无对应 read/open，`granularity=Phoneme`。本轮不猜测可用中国区端点，也不在浏览器暴露长期密钥。[官方配置](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/how-to-pronunciation-assessment)

响应始终 `seal=false`。L1 只有文字时 `overall=null`、`words=[]` 并注明只完成识别；L2 缺字段时保留缺失，L3 只根据可信诊断给出“字→词→短语”的教师审过的练习。开放说可先进行 L1 意义判题，再邀请学员对有疑问的目标词做独立朗读复测；这次朗读结果不能倒算为上一句开放说的发音成绩。

本地/私有方案需要 ASR、对齐、音素/声调声学模型、教师标注校准、GPU/CPU 容量与运维；Whisper 类 ASR 加强制对齐本身不能证明声调评测成立。自建费用必须等目标硬件、30 路吞吐、授权与样本规模确定后算；本次不给虚构“零成本私有化”或确定工期。断网底线是文字/拼音/点选完成教学，不是假称离线发音打分。

## 3. 模型选择、延迟与每课费用

模型仅负责受约束的短回复，不代替车的 `FACT`、站点判题、等级表或证据白名单。建议以**阿里云百炼北京地域 qwen-plus 非思考模式**作为首个中文 NPC 评测候选，选择理由是中文短对话、结构化输出与可核查国内地域价格；不是已经测出的最佳模型。固定通过验收的模型版本，别名升级后重跑评测。部署在学院内网的代理也不等于模型在内网；地域、数据处理条款由项目方/学院选择后配置。此建议不改变开发代理当前模型或服务档位。[模型与地域](https://help.aliyun.com/zh/model-studio/qwen-plus)

北京时间核查的公开非思考价格：输入 0.8 元/百万 token、输出 2 元/百万 token（北京，输入≤128k）。不计缓存折扣、批处理优惠或免费额。按每课每人 10–20 轮，每轮完整模型请求≤1500 输入 token、生成总额≤80 输出 token：

`模型费用 = 轮数 × (1500 × 0.8 + 80 × 2) / 1,000,000`

| 情景 | 每人每课估算 | 边界 |
| --- | --- | --- |
| 10 / 20 轮 NPC | 0.0136 / 0.0272 元 | 所有系统提示、事实、历史、JSON 字段都算 token；取上限算账 |
| 每轮都发生一次付费重试 | 0.0272–0.0544 元 | 不是正常成本预测；超时请求也可能已计费，靠厂商 usage/账单核对 |
| 腾讯短朗读 30–50 计费次（假设） | 0.15–0.25 元 | 0.005 元后付费；开放说/长文本折算单位另算 |
| 上述模型+短朗读组合，无重试 | 0.1636–0.2772 元 | 仅示例变量组合，不是成交报价或实测平均；不含额外 ASR、云 TTS、带宽、主机、私有化、税费/套餐闲置成本 |

模型价格依据[百炼模型页](https://help.aliyun.com/zh/model-studio/qwen-plus)，语音价格依据[腾讯计费页](https://cloud.tencent.com/document/product/1774/107342)。每班乘实际人数；按真实语音计费单位、模型 usage 与失败调用另出账单核验，不能只数前端成功回复。若实际运行换模型、换地域或启用思考，重算本表；80 token 的输出预算不包含无限思考额度。

80 token 是模型输出总额，不是只算中文对白。完整 `zh/en/teacher/evidence/...` JSON 可能超限，应使用紧凑生成字段并由服务端补确定性字段，或以实测 usage 如实更新费用，不能静默截断后宣称合格。每次请求历史≤6轮，再裁剪到总输入预算；白名单、事实和等级校验不可为省 token 删除。

三层兜底为模型→服务端脚本→浏览器本地脚本。仅长度/等级失败可在同一总时限内重试一次；事实冲突、错例越权或印章违规立即回退。五道校验必须用服务端可信课程数据，不能相信客户端传来的 `facts/allowedErrors`。小龙错句优先直接输出白名单原句，改编需保留原文、证据 ID、改编关系与教学审核，不能只附 ID 就称真实原句。

首字≤1.5秒、整句≤3秒仍是验收目标；“嗯”只表示等待，必须单独统计真正首字耗时，不能把占位音当模型通过。端到端计时包括代理、模型、校验/重试和前端呈现；预算到期应停止等待并走脚本。M0 文档没有证明任一模型已达这些指标。

## 4. 数据、隐私与部署

语料读取顺序为打包 40 条快照→服务端缓存→真实接口；无真实凭据不回源。缓存保存原文、来源、查询式、命中数、检索时间和缓存时间，TTL 至少 30 天；搜索键须包含 `channel/pattern/limit/page/window`，避免不同上下文窗口混用。材料中的约 4930 次与 2026-11-21 到期是交付快照，不能当当前余额/可用性。不得为探测接口反复登录重新签 Key。

录音默认不落盘、不写日志，不进入事件流、错误追踪或模型提示；前后端转码临时文件也在此禁令内。事件保留匿名随机 session、必要转写/分数和教学行为，教师面板默认班级聚合。随机 ID 与转写仍可能关联个人，不能称完全匿名；服务器访问日志不得把 IP、User-Agent、正文无期限存为学习档案。保存期限与删除方式需在真实开课前配置。

院校需决定中国内地云、批准的境外云或私有服务。未选择时云增强关闭；不能根据域名中文、代理部署地点或留学生国籍推断没有跨境处理。告知页应写清处理目的、供应商/地区、音频瞬时传输、转写/分数保存期限、退出方式；拒绝录音可使用同等文字/点选路径。浏览器麦克风权限弹框不能替代这些告知。

《个人信息保护法》涉及同意、自愿明确告知、敏感个人信息、未满14周岁监护人同意，以及向境外提供个人信息的特别要求。是否适用具体路径由机构依据实际数据/人员/部署确认；本项目不把“技术不落盘”宣称为已经完成合规。[全国人大通过的法律全文（网信办）](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)

## 5. 资产责任、里程碑与未定费用
