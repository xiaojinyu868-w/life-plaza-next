本机服务集成检查：

- 无供应商配置时，服务器按可信车辆事实回答“纯电动汽车有发动机吗”，来源为脚本。

- 390×844 视口无横向溢出；字幕英文底部约 601px，“继续”按钮顶部约 649px，没有遮挡。专业目标词仍标为超出当前等级并附英文。
- 教师页面成功读取 4 项汇总指标；测试事件仅进入 `.local/browser-check-data`，不冒充真实学生记录。
- 页面未捕获运行错误。检查中曾发现货架 DOM 被写回课程包并导致校验失败，已通过复制显示状态修复，随后重新跑通。

本地证据：`artifacts/browser/report.json`、`report-nev-l4-plugged.json` 及同目录截图。该目录不进 Git，命令可重现：先构建和启动独立测试服务，再运行 `npm run test:browser`。测试脚本可用 `WORKSHOP_TEST_CASE` 单独复测路径。
