# HSK 2025 词汇数据与判级边界

本数据用于改善 A06 的词汇覆盖和超出目标等级提示，不证明一句话的全部语义、语法或发音已经符合 HSK。数据文件为 `content/hsk/vocabulary-2025.json`，`schemaVersion: 1`。字幕、词卡及服务端共用 `src/lexicon.js` 和这份词表；旧 `src/hsk.js` 仅保留第三方例句、共字拓展与迁移比对，不再提供等级裁定。

- 官方入口为 [HSK 页面](https://www.chinesetest.cn/HSK) 与[大纲查询系统](https://www.chinesetest.cn/syllabus)。本次这两个页面连接失败，**没有取得官方 API 返回**；下述核查针对下载的 PDF，不称为官方 API 全量验证。
- 辅助拼音和英文取自本机保留的 Gushi `hsk-3.0-complete.json`，其 `updated` 为 `2026-10-14`，SHA256 `d1053319ab25ae3f4c00e0c28c78549a99f4e8a52d8842f46df07d11375d2b49`。

辅助源的准确 SHA256 也已写入 JSON 的 `sources`。其公开[下载 URL](https://gushichinese.com/hsk-3.0/downloads/hsk-3.0-complete.json)会更新，不能仅凭相同 URL 认为文件版本相同。本次未使用2026-11-08新下载文件的拼音、英文或识字数据。

Gushi 是第三方编纂者。其页面说明英文释义改编自 CC-CEDICT，拼音、选义和整理由 Gushi 完成；这些辅助字段不属于本次官方等级核查的认证范围。[来源说明](https://gushichinese.com/hsk-3.0/downloads)

## 精确结构

顶层字段为 `schemaVersion`、`id`、`version`、`sources`、`license`、`derivation`、`counts`、`words`。

| 字段 | 类型与含义 |
| --- | --- |
| `schemaVersion` | 整数，当前为1 |
| `id` | 字符串 `hsk-vocabulary-2025-11` |
| `version` | 对象：`syllabusPublished`、`syllabusImplementation`、`compiledAt`、`revision` |
| `sources` | 来源对象数组；含发布者、URL、源文件SHA256、使用字段、核查边界；第三方源另含日期、署名和许可 |
| `license` | 本词表的许可证、适用范围、署名与衍生说明；不改变软件仓库整体许可 |
| `derivation` | 词形合并、等级处理、辅助字段、不纳入内容和验证限制；保留中间提取结果SHA256 |
| `counts` | 唯一词形数、原始记录数、序号范围、分级记录数、多记录词形与补充等级统计 |
| `words` | 词条数组，按首次出现的官方序号排序 |

每个 `words[]` 只有如下字段：

```json
{
  "word": "对",
  "records": [
    { "serial": 44, "band": "1", "usageBands": ["4"] }
  ],
  "readings": ["duì"],
  "meanings": ["correct; a pair; to face"]
}
```

- `word` 为简体词形字符串。官方“本1／本2”“为1／为2”等同形词编号后缀仅在词形分组时移除，每条官方记录仍保留独立 `serial`。
- `records[].serial` 为官方词汇大纲序号，1–11000；不是重新生成的词条编号。
- `records[].band` 只允许字符串 `"1"`、`"2"`、`"3"`、`"4"`、`"5"`、`"6"`、`"7-9"`。
- `records[].usageBands` **仅放官方等级栏括号中的补充用法等级，不重复主等级**，值域与 `band` 相同。普通词是 `[]`；“对”`1（4）` 为主等级1、补充4；“电”`3（5）` 为主等级3、补充5。未根据词频或模型推断补充等级。
- `readings` 和 `meanings` 是旧 Gushi 同词形记录的非空、精确去重并集。两数组彼此不按下标对应，也不与 `records` 一一对应；不能将第一个英文释义自动解释为第一条官方记录的词义。空值检查不等于读音与释义质量核验。

## 核查结果

从 PDF 的词汇表按序号提取了11,000条记录，序号连续且唯一，无无法解析的词汇行。保存全部记录后，将官方同形词编号后缀规范化，并将 Gushi 的7/8/9归为共同等级7–9；旧源及今日下载源的**词形＋主等级多重集合**均与官方提取结果一致。比较保留重复记录，没有先去重掩盖缺行。

| 核查项 | 结果 |
| --- | ---: |
| 官方记录数 | 11,000 |
| 唯一词形数 | 10,896 |
| 存在多条记录的词形 | 99 |
| 超出唯一词形数的记录 | 104 |
| 有括号补充用法等级的官方记录 | 102 |
| 无辅助拼音／无辅助英文的词形 | 0／0 |
| 序号缺失／重复 | 0／0 |
| 主等级1／2／3／4／5／6／7–9新增记录 | 300／200／500／1000／1600／1800／5600 |

这是词形、主等级和序号的结构核查，加上括号等级的逐行映射检查；不包括全部拼音、词性、英文、例句、语法、考试题库的正确性认证。PDF七至九级词汇起始页与一级认读字末页另做了渲染抽查。原 PDF、提取JSON、比较结果和审计清单在忽略目录 `.local/hsk-audit/`，不随本词表提交到 Git。

## A06 如何使用

**七至九级只能作为共同等级。** 官方词汇序号5401–11000共用7–9；Gushi 将其分成约1867/1867/1866是自身学习进阶设计。“燃油”第8787条应显示7–9，不能称官方9级。[Gushi 对均分的说明](https://gushichinese.com/hsk-3.0/downloads)

**保留多读音、多义项和多等级。** “只”的量词 `zhī` 为1级、副词 `zhǐ` 为3级；“还”`hái` 为1级、`huán` 为3级。同一个词形的最早等级不能证明其当前用法已经在目标级内。项目可以对所有主等级与补充等级的并集取最高等级作保守标橙；但这会对某些低级用法产生额外提示，界面应说明是“多用法保守提示”，不能声称已进行语义消歧。级别区间7–9仍显示共同等级，不转换为官方单独7、8或9级。

**词汇等级与识字等级分开。** 本词表不包含认读字、书写字。原209条子集混入24个仅在识字表有的字，另有24个词的子集等级与官方词汇主等级不一致，例如：

| 词形 | 旧子集情况 | 本词表情况 |
| --- | --- | --- |
| 前 | 缺失，容易被当成未知词 | 官方词汇1级 |
| 句子、明白 | 缺失 | 官方词汇3级 |
| 为 | 子集2级来自认读字 | 词汇主等级3／4／5 |
| 认、识 | 子集均1级来自认读字 | 词汇主等级分别5、6 |
| 机、汽 | 子集分别1、3级 | 未单独列为词汇条目，不借认读字等级补填 |
| 电 | 词汇主等级3，但认读字为1 | 本词表主3、补充用法5 |

**词表扩大后仍需正确分词。** 当前使用完整词形最长匹配，优先保护课程 `professionalWords` 和名字；不能把“驱动电机”拆成若干低级字后称整词已达标。发动机、驱动电机、动力电池、制动、动能、能量回收未作为本版词汇表整词收录，应用标明“词表未收录／课程专业词”，不能编造HSK等级。教学中的“主语、动词”也作为完整术语提供英文支持。最长匹配尚不能解决所有中文切分歧义；未收录也不等于语言学意义上必然更难。

前后端均只用当前课程字典作释义与名字补充，避免第5课在浏览器中意外继承第4课的人名边界。词卡及明确的等级/读音查询可以访问完整词表；非课内拼音英文标为第三方词典资料，未生成语料印章。教师模式不做等级过滤。服务端模型校验和脚本兜底均检查字数及最多2个不同超目标词；多用法按最高级的保守策略可能增加提示或回退，不能把它解释为真实模型能力下降或已完成语义消歧。

词汇表不替代课程专业词名单、教学目标、语法检查、车的事实表或真实语料来源。即使词汇标注正确，A06仍需实际输出的分词、显示和教师审核证据；不能用本次数据核查代替50轮真实模型验收。
