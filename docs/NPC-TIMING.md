# 对话等待、语音播放与浏览器计时

当前实现仍先接收、校验完整回复，再一次显示答案。不会为了降低“首字时间”把未经事实/错例检查的模型片段显示给学习者。

## 等待时的行为

自由提问和答错后的补充讲解，如果900毫秒后仍没有回复，会尝试说“嗯，我想一想。”。这是固定的等待提示，不是模型回答，不盖语料印章。提示附拼音和英文；未在当前等级表确认的词仍标橙，不为这句话补造HSK等级。

收到答案后取消尚未完成的提示，开始显示和朗读答案。关闭对话、切换伙伴、开始录音、切换题目或断网会取消对应播放；旧回复不能覆盖新对话。补充讲解等待时保留本地判题和纠错提示。

声音仍受页面声音开关和可用中文语音影响。离线只选浏览器声明为本机的语音，联机可使用浏览器提供的其他中文语音。没有声音、声音启动太慢或播放失败时继续显示文字；不宣称所有浏览器都能发声。

`voice-output.js` 集中管理应用语音。只有浏览器 `onstart` 才算报告开始，只有 `onend` 才算报告结束；1200毫秒未开始、播放超时、取消和错误都返回明确原因。兜底计时器不再返回“播放成功”。浏览器事件仍不能证明扬声器实际有声或学习者听到了，真实听感需要另验。

## 记录的时间

用 `?debug=1` 打开课堂，可以在浏览器开发工具读取：

```javascript
window.__cdg.npcTiming.snapshot()
window.__cdg.npcTiming.clear()
```

记录从点击提交的处理函数开始，包含同步界面与检查开销。最多保留最近100轮，只存在当前页面内存中；不自动上传或落盘，不含问题、答案、录音、姓名、会话ID或凭据。

| 字段 | 含义 |
| --- | --- |
| `kind / role` | 自由提问或补充讲解，王明或小龙 |
| `responseReceivedMs` | 浏览器收到完整服务回复的时间，或本地回退完成时间 |
| `serverMs` | 服务端返回的处理耗时；未知时为空，不代替浏览器时间 |
| `answerFrameMs` | 写入答案后经过两次动画帧回调的时间，表示获得渲染机会，不是物理屏幕测量 |
| `cueRequestedMs` | 应用尝试播放固定等待提示的时间 |
| `cueSpeechStartMs` | 浏览器报告等待语音开始的时间；未开始则为空 |
| `answerSpeechStartMs` | 浏览器报告答案语音开始的时间；未开始则为空 |
| `cueSpeechResult / answerSpeechResult` | 正常结束、取消、无语音、启动/播放超时等结果 |
| `status / source` | 是否已渲染、取消或仅收到；答案来自模型、脚本或未知 |
| `modelFirstTokenMs` | 恒为空：当前不是模型流式首token测量 |

隐藏页面、已关闭对话或过期请求没有有效的答案渲染时间，不能按零毫秒计入成功。已显示的脚本回退也不能算模型按时回答。

## 对应A12验收

真实验收需用已获准的账号、部署地域、目标设备和网络条件。保存全部轮次，包括回退、取消、超时和无声音结果，再按预注册口径分别报告：模型有效内容出现时间、提示语音是否在1.5秒内开始、完整内容是否在3秒内获得渲染机会，以及答案语音启动时间。不能把固定提示计成模型首字，不能只取成功轮次。

`NPC-EVALUATION.md` 中的50轮工具记录服务端处理与实际用量；它没有自动取得这些浏览器字段。两份证据的测量范围不同，不能直接把服务端报告改名为端到端报告。

```powershell
npm run build
npm run test:response-ui
```

这条浏览器检查使用注入的模型延迟和合成语音事件，验证快回复不插话、慢回复提示、声音无法启动、关闭后迟到回复和本地纠错保留。输出位于 `artifacts/response-browser/`，明确标记 `realModelTested:false`、`realTtsAudioTested:false`，不能作为真实A12达标证明。
