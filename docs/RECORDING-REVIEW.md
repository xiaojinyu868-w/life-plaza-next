# 两份录音转写复核

材料：“标准录音 404”“标准录音 405”。复核于 2026-11-08。它们是讨论记录，不是其中每句话都已经成为用户指令。说话人编号与转写词语不稳定，不据此认定身份或对外背书。原始材料不入库。

## 核心产品

404 的具体目标是把平面教材转成有过程的中文训练：先有可理解的输入，再练习辨认和判断，逐步撤去提示，最后独立表达（26:31–30:45）。教师也应能沿着这一流程开展课堂，不只在 3D 场景点物品看词卡。职业车间提供语言情境，目标仍是学中文，不等于教授真实车辆维修操作。

405 解释了为什么要这样做：有些学习者基础弱、经常跟不上或不敢说，需要从“已经会的一个词”开始，获得具体回应和下一步支持（20:24–25:22）。这些教学动机不等于产品已经证明了心理、学习或商业效果。

## 落到当前实现的判断

| 讨论内容 | 对产品的要求 | 当前处理 |
| --- | --- | --- |
| 语料接入要体现前后变化（404 00:00–06:47） | 比较用法、例句、难度和偏误反馈，不能只展示接口成功 | 保留快照原句与检索记录；改写和生成单独标记；插电不等于实时回源 |
| 专业词优先但基础语法要简单（404 15:17–17:23） | 场景必需词与通用 HSK 等级分别记录 | 专业词仍可标超纲，并提供英语及拼音，不能把专业词排除后宣称全部符合 HSK |
| 学中文而非技能仿真（404 18:01–28:26） | 听懂、能说、能完成语言任务是主线 | 使用新能源汽车车间首课；真实维修训练不纳入验收 |
| 语言对应行动（404 31:01–33:17） | 正确指代与句式推动零件、车辆或任务反馈 | 保留场景动作与规则判题，模型不能直接宣布过关 |
| 学完后教会小龙（404 38:24–49:55） | 学习者讲述、解释并迁移，不能只是重复答案 | 当前保留教小龙和跨车种提问；仅一次答对不等于长期掌握 |
| 一个词也值得承接（405 20:24–25:22） | 给具体提示、示范与替代输入，不羞辱、不无限卡关 | 区分文字/点选、自报跟读、实际语音尝试；识别失败不当作知识错误 |
| 教育经验应该可复用（405 28:49–29:04、40:25–42:20） | 新课程用内容包表达，流程和反馈能够积累 | 推进课程 JSON 与第 5 课最小样例，保留教师观察数据的边界 |

## 没有在讨论中定案的部分

- 小龙应何时介入、是否和学生同时行动、关卡中纠错与课末复习如何避免重复，有明确争论（404 42:02–47:57）。不能把“小龙假装懂了”直接变成正式机制。支持性的语气也不能肯定错误知识。
- 小龙的名称、外观、长期成长机制、学生之间协作，并未形成完整可执行定义。代码中的人物只是当前教学原型。
- 自动上传任意教材就生成完整课程是愿景（404 28:26），不是当前已经可用的功能。
- 考试题库、基于国别的错题与统计、知识图谱先修关系，需要权限和真实数据验证。录音中的百分比和“独家”说法不转成产品宣传。
- “头”“机”等字的共字词链可以辅助复用，但不证明词源、词义或先修依赖；不能机械拆词制造解释。
- 正式学习效果应在真实学习者与教师审阅中验证；角色、渠道、资金、订单预测、亲历故事和相对截止时间不转成已确认的商务条件。
