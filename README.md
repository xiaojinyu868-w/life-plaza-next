# 人生广场 · 中文学习新项目

把中文教学内容变成可以进入、可以行动、可以开口的学习经历；让学习者在完成任务和教会学习伙伴的过程中，逐步建立能力与信心。

本项目承接人生广场的 3D 场景能力与学中文项目的学习层。借光与本项目无关。

## 本机运行

需要 Node.js 22 或更新版本，无需安装应用运行依赖。

```powershell
npm run build
npm start
```

打开终端显示的 `http://127.0.0.1:5198/`；教师汇总在 `/teacher.html`。入口可选第 4 课或第 5 课。配置参考 `.env.example`，真实凭据只放本机 `.env`。不要重新签发团队语料 Key 来试运行。

也可以直接双击 `dist/插电工坊.html`，无需服务器。此模式可以完成课堂，不能使用云对话、云语音或教师汇总。

“插电”控制语料快照的教学展示；“联机”控制是否使用服务器，二者独立。初始为离线模式，只有启用“联机”后才发送学习事件。离线语料沿用交付包记录，本次没有重新查询平台核验。

## 验证

```powershell
npm run test:rules
npm run test:layout
npm run test:flow
npm run test:flow:unplugged
npm run test:services
npm run test:lexicon
npm run test:model
```

规则和假 DOM 流程测试验证教学逻辑；服务端测试使用隔离目录及假供应商，不调用收费服务。真实浏览器、真实供应商和真人测评分别验收，不能把自动测试结果当成教育效果。

可选浏览器检查：先 `npm ci` 安装开发依赖，在另一个终端保持本机服务运行，再执行 `npm run test:browser`。默认使用已安装的 Edge；可设 `PLAYWRIGHT_CHANNEL=chrome`，并用 `WORKSHOP_BROWSER_ARTIFACT_DIR` 指定独立输出目录。默认报告和截图在 `artifacts/browser/`。脚本使用自动输入，不能替代真人语音与教学审阅。测试服务建议用独立的 `WORKSHOP_DATA_DIR`，以免把测试会话混入正式课堂。

`npm run test:portable` 不需要后端：把生成的HTML复制到系统临时目录，确认目录内只有该文件，在浏览器断网模式下跑两课的三条路径。脚本先以独立页面验证网络请求确实被断网拦截，再检查课堂没有HTTP或其他本地资源依赖。报告 `report-portable-offline.json` 包含构建/副本哈希与位置，副本留在临时目录方便复查。这验证同机跨目录和浏览器断网，不代表所有电脑、核显或真实语音都已通过。

`npm run test:speech-ui` 自行启动隔离测试服务，检查桌面和手机的跟读、失败、关闭、切题与断网流程；使用合成麦克风和假供应商回复，不上传真人录音。可选 `node scripts/browser-splat-check.cjs <本地500k官方v3样本路径>` 需要提前取得验证样本，不会下载或内嵌素材；报告在 `artifacts/splat-browser/`。

`npm run test:npc-ui` 检查自由语音问答、两次错答反馈、车型指代与对话关闭；同样只用模拟供应商。`npm run eval:npc:plan` 生成50轮清单和待审模板，实际执行轮数为0；显式真实调用及审核方法见 NPC 验收工具文档。

原始转写、教材原页、凭据、运行数据与交付 ZIP 不进入 Git。保留 HSK 数据署名，见 [NOTICE.md](NOTICE.md)。

新模型实际课堂检查：`npm run test:characters:browser`；新版排布检查：`npm run test:layout:browser`。均需先构建，并使用已安装的 Edge。模型检查包含两款真实生成 GLB、重复切换、资源释放、失败恢复及桌面/手机截图，不调用 Tripo。

本机 `deliverables/` 保存双形象离线 HTML、修订后的 Word 演示手册，以及 2分46秒的“制作过程＋完整课堂”无音轨录像；生成交付物不进入 Git。录像采用脚本辅助文字操作，前63秒为实际本地材料过滤、模型加载和构建，后续是完整六站课堂。复录制作段可运行 `node scripts/record-production.cjs`，需 Playwright、Edge 和 PATH 中的 `ffprobe`；它只读取已有模型，不提交收费生成任务。该工具是录制辅助，不是教师上传教材自动生课的产品入口。
