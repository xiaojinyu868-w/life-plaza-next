# t10 提供的古风室内点云

本资产从用户提供的根目录 `t10.html` **静态提取**，不是重新生成、降采样或执行原 HTML 后导出的文件。提取器只接受严格 JSON 与规范 Base64，拒绝可执行表达式、字符串拼接及重复赋值。

```powershell
node scripts/extract-t10-scene.mjs --self-test
node scripts/extract-t10-scene.mjs
```

重复运行只接受字节相同的已有输出，遇到不同文件拒绝覆盖。脚本读取当前项目的可信 SPZ 解码器及渲染器，未执行 `t10.html` 或 ZIP 内的脚本。

## 坐标和接入建议

原坐标的完整范围如下；极端值包含稀疏外围点，不应直接当作可站立房间边界。

| 轴 | 最小值 | 最大值 | 全体点 5%–95% |
|---|---:|---:|---:|
| X | -3.204102 | 3.777832 | -1.226563–1.351807 |
| Y | -2.504150 | 1.218506 | -1.800537–1.111328 |
| Z | -13.403076 | 18.169434 | -1.254883–5.654297 |

没有 metricScale，单位只能称“未标定场景单位”。原 HTML 的代码默认是 `scale:1, flip:true, y:1.5`，之后按分位数自动对齐；它也允许浏览器 localStorage 覆盖。**HTML 中无法恢复用户浏览器当时保存的摆放参数。**

当前 renderer 的固定空间样本得到的自动对齐候选为：

```json
{"scale":1,"yaw":0,"flip":true,"x":1.13505859375,"y":1.10693359375,"z":2.7102783203125}
```

这是当前算法的候选，并非从 HTML 取出的原始 PLACE。样本估计范围为 X `[-0.113477,2.513477]`、Z `[-3.492603,4.092603]`、高度约 `3.023438`，即宽约 2.627、深约 7.585 场景单位。原 HTML 使用不同的间隔样本，自动结果略有差异，两份计算均记录在 scene manifest。

这一区域在当前比例下容不下现有约 6.4×4.3 的举升工位和三车展示区；把场景任意放大也不能把古风室内变成汽车车间。建议将此文件用于“用户 t10 场景示例”或独立场景检查，继续为职业课程准备符合教学空间的车间。若主项目明确决定试装本资产，构建器的 `MARBLE` 可指向此 `.spz`；原 META 为空，scene manifest 也不是厂商提供的 META。PLACE 应经过构图检查再固定。
